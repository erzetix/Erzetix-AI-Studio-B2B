# Дорожная карта

## Этап 1 — завершён

**Разработка технического задания для программно-технологического комплекса для автоматизированного производства медиаконтента.**

Выполнено:

- Анализ имеющегося задела: опыт коммерческого производства AI-контента, опыт ведения виртуального персонажа
- Разработка технического задания на комплекс
- Проектирование архитектуры мультиагентной системы
- Определение состава подсистем и распределения зон ответственности
- Фиксация контрактов передачи данных между подсистемами
- Определение схемы производственного конвейера и правил переходов между состояниями кампании

## Этап 2 — в разработке

Продолжительность — 11 месяцев.

### Разработка API-оркестратора контент-пайплайна

- Реализация маршрутизации вызовов подсистем согласно схеме конвейера
- Реализация обращения к внешним генеративным сервисам с переключением на резервных провайдеров
- Реализация учёта состояния кампании и числа циклов доработки
- Реализация журнала выполнения этапов

### Разработка системы виртуальных бренд-персонажей

- Формирование параметров визуальной идентичности персонажей
- Формирование голосовых характеристик
- Формирование поведенческой логики и шаблонов сценариев
- Развёртывание защищённого хранилища параметров идентичности

### Реализация подсистем-агентов

- Ядро персонажа
- Агент-аналитик трендов
- Агент-стратег
- Агент-креатор
- Агент-визуализатор
- Агент-хранитель бренда

### Реализация рабочего контура команды

- Рабочее место команды
- Контур Human-in-the-Loop: утверждение каждого материала специалистом, возврат отдельных материалов на доработку с замечаниями
- Согласование отдельных материалов с компанией и фиксация решений компании
- Модуль публикации с вводом показателей эффективности
- Автоматическое формирование отчётов об эффективности

### Реализация контура обратной связи

- Агент-аналитик метрик
- Система A/B-тестирования

### Калибровка параметров

Определение значений параметров, не установленных на этапе проектирования:

- Пороговое значение оценки применимости тренда и метод оценки
- Пороговое значение оценки визуальной консистентности и метод сравнения
- Предельное число попыток генерации по фактической статистике
- Предельное число циклов доработки
- Предельное число концептов в контент-плане
- Условия эскалации агента-хранителя бренда на модель более высокого уровня возможностей
- Параметры повторных вызовов подсистем при недоступности

### Тестирование

- Тестирование комплекса на стабильность работы производственного конвейера
- Тестирование качества генерации медиаконтента
- Тестирование сценариев отказа внешних провайдеров

## Последующие этапы

- Государственная регистрация программы для ЭВМ и базы данных
- Расширение клиентской базы и масштабирование производственного конвейера
- Автономная публикация контента с прямой интеграцией в API платформ
- Развитие системы A/B-тестирования и автоматической оптимизации контента

## Целевые показатели

- Производство не менее 70 концептов контента в неделю силами команды из 3–4 человек в контуре утверждения
- Снижение зависимости роста численности персонала от роста объёма заказов за счёт автоматизации производственного конвейера
